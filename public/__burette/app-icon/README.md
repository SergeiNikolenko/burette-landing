# Workspace application icon

`finder.png` is the original Finder icon exported by Burette's browser-dev
asset route from the macOS Finder application. The image is resized from Burette's local app-icon cache, to satisfy the same published workspace
URL on the landing host. It identifies Finder inside the real Burette UI.
Apple retains ownership; this artwork is not covered by the source MIT license.

Editor icons identify installed application bundles: Maestro (2026-2), ChimeraX (1.10), PyMOL, Avogadro2 and DataWarrior. PNGs were extracted from their bundled ICNS artwork without redrawing. VESTA uses the [official site icon](https://jp-minerals.org/vesta/img/vesta-icon.png), linked by its product page. Burette and the default-app entry use the Burette bundle icon.

Menu PNGs are reduced to a maximum of 128 pixels to avoid loading full-size ICNS images. The Burette loader icon uses the same asset.
