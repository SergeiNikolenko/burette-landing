# Burette Documentation

Preview molecular files in Finder, then open the Mac workspace to inspect structures, compare compounds, and edit molecules.

These guides were reviewed against [Burette 2026.9.9](https://github.com/SergeiNikolenko/Burette/releases/tag/v2026.9.9) on September 23, 2026. The hosted plugin is deployed separately. Features and controls can differ between the desktop app, Finder preview, browser demo, and source-built iPhone app.

## Start here

1. [Install Burette](/docs/get-started/install) and open it once.
2. [Preview your first file](/docs/get-started/quick-start) with Space in Finder.
3. [Open the desktop workspace](/docs/surfaces/desktop) for tabs, editing, and analysis.

## Choose a surface

| Surface | What it provides |
| --- | --- |
| macOS app | The desktop workspace, file saving, collections, editing, and supported local calculations. Metal acceleration requires compatible Apple hardware and a working compute runtime. |
| Finder Quick Look | Structure, collection, and other supported file previews. Full desktop editing and calculation workflows are not available here. |
| Website demo | A browser preview of selected workflows. Local application launching, native compute, and filesystem integration are not equivalent to the Mac app. |
| Local Codex plugin | An inline molecular workspace and tools for supported local viewer or desktop sessions. |
| Hosted ChatGPT plugin | Authorized molecular attachments and public PDB entries in a chat widget; separate from local desktop access. |
| iPhone source app | Document previews built with Xcode; not installed by the macOS Homebrew cask. See [mobile scope](/docs/surfaces/mobile). |
