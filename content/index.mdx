# Burette Documentation

Preview molecular files in Finder on macOS, or open the Burette desktop workspace on macOS, Windows, and Linux to inspect structures, compare compounds, and edit molecules.

GitHub releases ship desktop builds for **macOS**, **Windows**, and **Linux** together. The hosted plugin is deployed separately. Features and controls can differ between the desktop app, Finder Quick Look (macOS), browser demo, and source-built iPhone app.

## Start here

1. [Install Burette](/docs/get-started/install) for macOS, Windows, or Linux.
2. [Open your first file](/docs/get-started/quick-start) (or press Space in Finder on macOS).
3. [Open the desktop workspace](/docs/surfaces/desktop) for tabs, editing, and analysis.

## Choose a surface

| Surface | What it provides |
| --- | --- |
| Desktop app (macOS, Windows, Linux) | The full desktop workspace, file saving, collections, editing, ligand interaction maps, and local calculations. Metal GPU acceleration runs on Apple Silicon; Windows and Linux run the CPU reference compute paths. |
| Finder Quick Look (macOS) | Structure, collection, and other supported file previews directly in Finder. Full desktop editing and calculation workflows are not available here. |
| Website demo | A browser preview of selected workflows. Local application launching, native compute, and filesystem integration are not equivalent to the desktop app. |
| Local Codex plugin | An inline molecular workspace and tools for supported local viewer or desktop sessions. |
| Hosted ChatGPT plugin | Authorized molecular attachments and public PDB entries in a chat widget; separate from local desktop access. |
| iPhone source app | Document previews built with Xcode; not installed by the macOS Homebrew cask. See [mobile scope](/docs/surfaces/mobile). |
