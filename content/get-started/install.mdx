# Install Burette

Burette supports macOS 12 and later.

## Homebrew

Install from the Burette tap:

```bash
brew tap SergeiNikolenko/burette
brew install --cask burette
```

Check the installed cask version:

```bash
brew info --cask SergeiNikolenko/burette/burette
```

## GitHub Releases

You can also install manually:

1. Open the [latest release](https://github.com/SergeiNikolenko/Burette/releases/latest).
2. Download the `Burette-<version>.dmg` or `Burette-<version>.zip` file.
3. Open the DMG or unzip the archive.
4. Move `Burette.app` to your `Applications` folder.
5. Open Burette once from `Applications`.

## First launch

Open `Burette.app` once after installation. This gives macOS a chance to register the app bundle and Finder Quick Look extension.

Signing and notarization depend on the release build. If macOS blocks the downloaded app, first confirm it came from the official release page. Follow the first-launch instructions for that release; macOS may offer approval in **System Settings → Privacy & Security**. Do not disable Gatekeeper globally.

If Finder previews do not appear after install, open Burette's command palette
and run **Reset Quick Look**. **Open Logs Folder** and **Export Diagnostics**
are available there as well.

## Updates

For a Homebrew installation, run:

```bash
brew update
brew upgrade --cask burette
```

For a manual installation, replace the app with the version from the latest release. Keep your project files; an app update does not require deleting them.

## Codex plugin and local MCP

The optional Codex integration lives in the same [Burette repository](https://github.com/SergeiNikolenko/Burette) as the app. It bundles workflow skills with typed MCP tools for opening, observing, and controlling a local molecular workspace.

Install Git, Bun, and Codex first. Clone the repository and run the plugin installer:

```bash
git clone https://github.com/SergeiNikolenko/Burette.git
cd Burette
bun run install:plugin
```

Restart Codex after installation, then mention `@Burette` or select Burette from Plugins. See [Codex Plugin and MCP](/docs/plugin) for the tool surface, security boundaries, and source links.

## Optional local calculation engines

The Burette application does not bundle xTB, CREST, or PRISM. Install only the engines needed for your local workflow:

```bash
pixi global install xtb
pixi global install crest
uv tool install prism_pruner
```

These commands require Pixi or uv to be installed first. For xTB, Settings can instead install a Burette-managed environment when Pixi or Conda is available. Check each executable, then use the matching runtime check in the desktop inspector. See [xTB calculations](/docs/workflows/xtb) and [CREST and PRISM](/docs/workflows/crest-prism).
