# Quick Start

## Finder Quick Look

1. Select a supported molecular file in Finder.
2. Press Space.
3. Use the preview for a fast visual check before opening the full workspace.

Quick Look is optimized for quick file previews. It is not the same runtime surface as the desktop app.

## Desktop workspace

Open Burette directly when you need a persistent workspace:

- `Cmd+O` opens molecular structure files.
- `Cmd+P` or `/` opens the command palette.
- `Cmd+,` opens settings.
- The sidebar browses project folders, nested structures, and recent files.
- Drag a file into the workspace to open it. Drop a molecule onto a supported collection or editor to see the available actions.

## What to try first

- Open a PDB, CIF, SDF, MOL2, XYZ, or GRO file.
- Switch between available renderers when the preview exposes that option.
- Open an SDF, SMILES, CSV, or TSV collection to use the RDKit grid.
- Open a DataWarrior, RXN, or RDF file to inspect its table or reaction records.
- Open the collection’s analysis actions for descriptors, clustering, similarity, and Chemical Space. Availability depends on the selected records and runtime readiness.
- Drop compatible records onto the open grid to append them, or merge complete collections from one format family.
- Open the inspector for a small molecule or selected Mol* object to find the optional local xTB and CREST workflows.
- Use Settings or the command palette for Quick Look reset, preview cache cleanup, logs, diagnostics, and maintenance.

## When previews fail

Open the command palette and run **Reset Quick Look**. Use **Open Logs Folder**
or **Export Diagnostics** if the reset does not restore the preview.

Then see [Quick Look troubleshooting](/docs/troubleshooting/quick-look).
