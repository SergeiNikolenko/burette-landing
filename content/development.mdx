# Development

The main Burette repository contains the desktop app for macOS, Windows, and Linux, the macOS Quick Look extension, the source-built iPhone preview app, bundled web runtimes, agent tools, and documentation.

## Set up a checkout

Install Git, Bun, Rust, Xcode, and the Vite+ CLI as described in the repository’s [build guide](https://github.com/SergeiNikolenko/Burette/blob/main/docs/installing-building.md). For frontend work:

```bash
vp install
vp dev
vp check
```

Native macOS app and Quick Look builds require macOS and Xcode. Linux bundles (`./scripts/build-linux.sh`) build on x86_64 Linux with WebKitGTK 4.1, and Windows installers (`./scripts/build-windows.sh`) build on Windows x64 with MSVC and Git Bash. Every GitHub Release (`.github/workflows/release.yml`) builds and publishes macOS, Linux, and Windows packages together.

## Source of truth files

| File | Owns |
| --- | --- |
| `config/preview-formats.json` | Supported file extensions, content types, renderer routing, grid routing, Quick Look limits, and VESTA handoff flags. |
| `config/web-runtime-profiles.json` | Bundled web runtime assets for Tauri, Quick Look, grid, Mol*, and external-artifact profiles. |
| `apps/desktop/src-tauri/AppMetadata.plist` | App-level document type metadata used by the Tauri bundle. |
| `PreviewExtension/Info.plist` | Finder Quick Look preview extension metadata and supported content types. |
| `PreviewExtension/ThumbnailInfo.plist` | Finder thumbnail extension metadata and supported content types. |
| `apps/desktop/src-tauri/tauri.conf.json` | Tauri bundle metadata, resources, app identifiers, update config, and macOS file associations. |
| `packaging/linux/` & `packaging/windows/file-associations.json` | Linux desktop entry/MIME XML and Windows file-association overlays generated by `scripts/desktop-metadata.mjs`. |
| `config/xyzrender/requirements*.txt` | Pinned `xyzrender` and RDKit runtime locks for macOS arm64, Linux x86_64, and Windows x64. |

## Format registry check

When a preview format or document type changes, keep the registry, macOS plist files, Linux/Windows desktop metadata, and focused format tests in sync:

```bash
bun scripts/check-preview-format-registry.mjs
node scripts/desktop-metadata.mjs --check
```

## Quick Look development

Use a unique development flavor for local packaged builds:

```bash
BURETTE_DEV_FLAVOR=docs-check ./scripts/build.sh
BURETTE_DEV_FLAVOR=docs-check ./scripts/install.sh
```

Then refresh Quick Look:

```bash
qlmanage -r
qlmanage -r cache
killall quicklookd 2>/dev/null || true
```
